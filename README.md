# netlify-food

這是一個用於 Netlify 部署的簡單前端應用，主要功能是根據目前位置搜尋附近餐廳，並提供「今天吃什麼」的隨機推薦體驗。

## 功能說明

- 單頁應用程式，使用 `index.html` 提供 UI 和前端邏輯。
- 透過 Netlify 函式 `netlify/functions/places.js` 呼叫 Google Places API。
- 支援定位權限，搜尋附近餐廳並顯示距離、地址與分類。
- 可編輯自定義分類，讓使用者調整篩選項目。
- 可部署為 PWA，支援行動裝置上的獨立顯示。

## 目錄結構

- `index.html`：前端頁面與應用程式 UI。
- `netlify/functions/places.js`：後端 Netlify 函式，代理 Google Places API 請求。
- `netlify.toml`：Netlify 部署設定。

## 部署與設定

1. 在 Netlify 專案中，設定環境變數 `GOOGLE_API_KEY`。
2. 將專案部署到 Netlify。
3. 使用者開啟應用後，允許瀏覽器存取位置資訊。
4. 應用會透過函式呼叫 Google Places API，取得附近餐廳清單。

## 注意事項

- `GOOGLE_API_KEY` 必須具備 Google Places API 的存取權限。
- 若未設定 API Key，函式會回傳錯誤訊息 `Missing API key`。
- 搜尋結果會依使用者所在地點與半徑參數而有所不同。

## 使用手冊

### 1. 開啟應用

- 進入部署後的 Netlify 網頁。
- 首次使用時，瀏覽器會要求「允許存取位置」。請選擇「允許」。

### 2. 查詢附近餐廳

- 應用會自動讀取位置並顯示目前位置狀態。
- 若成功取得位置，畫面會顯示附近餐廳的清單和距離。
- 若無法定位，請確認瀏覽器位置權限已開啟，或點擊「重新定位」按鈕。

### 3. 使用隨機推薦

- 點擊畫面中的「隨機按鈕」可以隨機選擇餐廳類別。
- 向上或向下滑動分類輪盤，可切換不同餐廳類別。
- 若點擊分類區塊，會展開分類選單供快速切換。

### 4. 編輯自定義分類

- 點擊右上方的「編輯分類」按鈕。
- 在彈出視窗中新增、新增分類名稱，或刪除不需要的分類。
- 編輯後會直接更新應用內的篩選選項。

### 5. 使用 Google 地圖導航

- 在餐廳項目中，若有顯示導航按鈕，可直接開啟 Google 地圖查詢路線。
- 點擊餐廳卡片或按鈕後，會跳轉到 Google 地圖頁面。

## PWA 應用

- 本專案包含 Web App Manifest，支援安裝到行動裝置的主畫面。
- 在支援 PWA 的瀏覽器中，會出現「加入主畫面」或「Install」選項。
- 安裝完成後，可像原生應用程式一樣從主畫面啟動。
- 若要安裝：
  - Android / Chrome：點選瀏覽器選單，選擇「加入主畫面」。
  - iOS / Safari：點選分享按鈕，選擇「加入主畫面」。
- 注意：此應用目前未內建完整 Service Worker 緩存策略，離線可用性可能有限，建議保持網路連線。

## 本地開發

若要在本地模擬 Netlify 函式，可使用 Netlify CLI：

```bash
npm install -g netlify-cli
netlify dev
```

然後在瀏覽器開啟本地端伺服器地址，即可測試應用與函式。
